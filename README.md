# Motion Design Showcase ✨

一个纯 HTML / CSS / 原生 JavaScript 打造的**高级动效设计展示页面**，充分展现流畅、精准、富有情感的运动设计实力。

**在线预览**：部署 GitHub Pages 后访问  
`https://doraemonRain.github.io/motion-design-showcase/`

## 动效亮点

- **Hero 入场动画**：渐变文字流动 + 弹性淡入
- **浮动光球 & 粒子上升**：营造沉浸氛围
- **鼠标跟随光晕**：全局光效
- **卡片悬停光效**：径向渐变跟随鼠标
- **Morphing Blob**：有机变形动画
- **3D Tilt Card**：鼠标驱动的三维倾斜
- **Magnetic Button**：磁吸交互 + 填充动画
- **滚动揭示**：Intersection Observer 驱动的入场动效
- **时间轴动效**：设计之旅可视化

## 技术栈

- 纯前端，无框架、无依赖
- 现代 CSS（自定义属性、渐变、滤镜、transform）
- 原生 JS（鼠标追踪、3D 倾斜、Intersection Observer）
- 精心调校的 `cubic-bezier(0.16, 1, 0.3, 1)` 弹性曲线

## 本地运行

直接打开 `index.html` 即可，或使用任意静态服务器：

```bash
npx serve .
```
